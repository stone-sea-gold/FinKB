# 解析成功率指标（八份文档）

指标口径：**有表头** = 逻辑表拿到了列名（自身或继承）；**有归属** = 至少拿到 `section_path` /
`caption` / `period_label` / `table_title` 之一；**裸表** = 既无表头、也无分节路径与表外标题
——这类表下游只能靠列位置猜语义。

## 怎么用

- 改判据前后各跑一次这张表，**只看有没有表头与裸表的数量变化**，比逐张汇报更容易发现回归
- 裸表不是都错：短键值表本来就没有列名（`kind=kv_row` 是设计如此）。但数量突然上涨一定有问题
- 601127 两份的裸表比例明显更高（14% / 10%），是下一个值得解剖的对象
