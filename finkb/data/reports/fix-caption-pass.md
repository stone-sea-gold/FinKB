# 表外标题（caption）回溯修正 · 核验报告

改动对象：`src/finkb/parser/mineru_client.py` 的 `_resolve_caption()` / `_resolve_period()`。

## 一、为什么改

D 类 4 张表的表名没取到，成因三种：

| 表 | 表面现象 | 真因 |
|---|---|---|
| `P105_T94` / `P106_T95` | caption 是「本集团以共同信用风险特征为依据…」 | 表格上方那句是**说明文**，真名在它上面一层的标题 |
| `P187_T242` | caption 是「2025 年度本集团由于战略调整新设了 9家子公司…」 | 同上，真名是**上一页**的「5.1 本年新设子公司的情况：」 |
| `P167_T193` | caption 是「无」 | 那个「无」是**上一张表溢出到本页底部的数据格** |

## 二、改了什么

1. **以「。」收尾的整句不是表名**，继续往前找。
2. **≤2 字的块不是表名**，跳过（「无」「是」「否」这类溢出格）。
3. **长段落也不是表名**，继续往前找（原先直接判「没有」）。
4. **回溯时校验版面坐标**：MinerU 的内容列表不是版面序，个别块排在表格前面但物理上在表格下方（赛力斯 p72 / p167 两处），按 `bbox` 上边距跳过。
5. **期间标签改为回溯**，可跨过单位行与复选框（原先只认紧邻），但遇到别的块就收工，不会把上一张表的年份安过来。
